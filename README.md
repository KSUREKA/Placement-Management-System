# 🚀 PlacePro - Placement Management System

## 📌 Project Overview

PlacePro is a web-based Placement Management System developed to manage student details, company details and placement information.

The system helps placement administrators maintain placement records in an organized and simple way.

## 🎯 Objectives

- Manage student information.
- Manage company information.
- Track student placement status.
- Search student records.
- Calculate the placement percentage.
- Reduce manual paperwork.
- Improve placement record management.

## ✨ Features

### 👨‍🎓 Student Management

- Add student details.
- View student records.
- Search students.
- Edit student details.
- Delete student records.
- Store placement status.

### 🏢 Company Management

- Add company details.
- View company records.
- Delete company records.
- Store job role and salary package.

### 🎯 Placement Dashboard

- Display total students.
- Display total companies.
- Display placed students.
- Calculate placement rate.

## ▶️ How to Use

1. Open the Placement Management System website.
2. Go to the Student Management section.
3. Enter student details.
4. Click the Add Student button.
5. Add company details in the Company Management section.
6. View placement details in the dashboard.
7. Use the search box to find students.

## 👨‍🎓 Student Details

The student module contains:

- Student ID
- Student Name
- Email Address
- Department
- Company Name
- Placement Status

## 🏢 Company Details

The company module contains:

- Company ID
- Company Name
- Job Role
- Salary Package

## 🔐 Validation

The system uses basic form validation:

- Student name is required.
- Email address is required.
- Department is required.
- Placement status is required.
- Company name is required.
- Job role is required.
- Salary package must be a valid number.
